# Theme art: production brief (PixelLab)

Project: this repository (NorthLight Tower: a tool that shows Claude agents in a pixel-art tower).
The tower ships a "cyberpunk" look by default; themes swap only the images. The system and layout stay the same.
For every theme we produce the same 30 furniture/decoration parts at **exactly the same pixel size as the cyberpunk ones**.

## Files
- `tools/theme_sprites.json`: the 30 parts: `name`, `w`,`h` (final size), `canvas` (PixelLab generation canvas), `anchor`, `role`.
- `_work/theme_refs/<name>.png`: cyberpunk reference (placed bottom-center on the canvas); the uploaded version is in `_work/theme_refs/refs.json` (`<name>` -> `upload:<id>`, valid for 3 days).
- `theme_defs.py`: each theme's `art.palette` (16 colors) and `art.style` / `art.skyline` text. **Use this palette and style text.**
- `tools/theme_sprites.py fit <theme> <name> <downloaded.png>`: crops, downsizes if needed, aligns bottom-center and saves at FULL size as `assets/themes/<theme>/f/<name>.png`. `check <theme>` lists missing files and wrong sizes.
- Raw downloads: `_work/theme_raw/<theme>/` (create the folder yourself).

## Generation method (tried, works)
With `mcp__pixellab__create_object_pro_flash`, per part:
```
description  = "<theme-specific object name + material>, <art.style>"   (from the table below)
width,height = spec.canvas[0], spec.canvas[1]
n_directions = 1
view         = "low top-down"        # the cyberpunk parts use this angle: 3/4 from above, dark outline
palette      = theme_defs art.palette (16 hex)
style_image  = {"url": refs[<name>], "usage_description": "same canvas, same camera angle, same silhouette proportions, size and pixel density; restyle only, do not copy the colours"}
seed         = 3  (try another seed if it comes out badly)
```
Cost is about 5 generations per part. Start several jobs in the SAME message in parallel (10 at a time) and wait with `wait_for_jobs`.
Download the result (no key needed):  `curl -sS -L -o _work/theme_raw/<theme>/<name>.png "https://api.pixellab.ai/mcp/objects/<object_id>/download"` -> then `fit`.
With an 80x60 canvas the output is 80x60; the sprite comes out centered in the canvas, and `fit` crops and aligns it.

## Rules
1. **Fixed size**: after `fit`, `check <theme>` must report no wrong sizes. If the generated sprite spills outside its original box, `fit` scales it down proportionally; if it comes out too small (under half), regenerate (change the seed or add "fills the whole canvas, large" to the description).
2. **Same viewpoint**: 3/4 top-down (`low top-down`), NO background, dark outline. Standing parts are seen from the front-top and rest on the floor.
3. **Consistency**: all 30 parts from the same palette and the same material language (e.g. western: oak planks + iron + brass).
4. **Wall decorations** (`poster_*`): framed picture/poster; **no text in it**.
5. NO monitor/computer ON `desk_b` (monitors are drawn by code; the desk surface stays empty). `exec_desk_clean` is also empty on top (a lamp is fine, but no laptop/screen). Keep a drawer block on the right side of the desk front (the right-front area of `desk_b` must stay plain for the name plate: a flat surface at about x 49..78, y 33..45). `exec_desk_clean` needs a flat plate area in the middle of its front (about x 60..85, y 40..46).
6. Bright/neon colors only as small accents; the theme keeps a natural warm/cool balance.
7. Check every part by eye when done (open the image; make one contact sheet scaled 4x with Python and look at it). Regenerate the bad ones once; if still bad, keep the best one and say so in the report.
8. Write only into your own theme's folders (`assets/themes/<theme>/f/`, `_work/theme_raw/<theme>/`). Do NOT touch other files, `scene.json` or code files. Do not touch a running server (port 8765).

## Sky (outside the windows): 2 images
`mcp__pixellab__create_image_pixflux` (1 generation each); the difference is `no_background`:
- **far**: 400x200, `no_background=false`: the theme's `art.skyline` text, far layer (sky + distant silhouette). It repeats horizontally (the code mirrors and joins it): keep it nearly symmetric and plain at the edges so the seams are clean. Save as `assets/themes/<theme>/bg/skyline_far.png` (400x200).
- **near**: 400x160, `no_background=true`: near-layer silhouette (roofs / rocks / trees, dense at the bottom); save as `assets/themes/<theme>/bg/skyline_near_keyed.png` (400x160, transparent background).
Windows only show the bottom-middle part; the main area of interest is the top half of the image (far) and the bottom half (near).
If the output is not exactly 400x200 / 400x160, resize with `PIL` and `Image.NEAREST` (keep the aspect ratio first, crop the edges).

## Handover
When done, write: the number of parts produced/missing (the `check` output), the names of the ones you found bad, the total generations spent, and the path of `_work/theme_sheet_<theme>.png` (a 3x contact sheet of the 30 parts + the two sky images).
